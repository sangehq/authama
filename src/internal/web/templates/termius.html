Import into Termius

  1. Download the file above, or copy it.
  2. In Termius: Hosts → New Host (the arrow beside it) → Import → CSV, click Skip download, and choose termius-hosts.csv.
  3. The CSV carries no SSH keys (Termius's template has no column for them), so attach each host's key as below. Until then, connecting stops at SSH key selection.
  4. Importing again after a change can add duplicates: Termius does not say how it treats hosts it already has.
