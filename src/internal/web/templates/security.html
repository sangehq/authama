If you forget the PIN

A forgotten PIN is replaced at a terminal on this machine: the reset reads the sealing key from your account's own credential store, which is how it knows you are you, and it needs no old PIN. A browser cannot prove that, so this page never resets a PIN. A PIN is only set when this reset would work, so it cannot lock you out.
