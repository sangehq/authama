Export

The setup document is JSON you can read, diff and keep in a repository. It holds:

  • {{.Profiles}} profile(s), their hosts and the manifest's defaults
  • {{if .Providers}}the providers{{else}}no providers.json{{end}}, {{if .Settings}}the settings (without this machine's paths){{else}}no settings file{{end}} and {{if .Tokens}}the token config{{else}}no token config{{end}}
  • the names of {{len .EnvNames}} variable(s) tokens are read from{{if .EnvNames}}: {{range $i, $n := .EnvNames}}{{if $i}}, {{end}}{{$n}}{{end}}{{end}}

It carries no private key and no token value. The {{len .Keys}} key(s) the manifest declares are listed by name only; on the new machine authama ssh reconcile makes them, or the encrypted export brings them.

{{icon "download"}}Download the setup document {{template "command_line" .ExportCmd}}

Everything, encrypted

The full export adds every private key, the inventory and the values of the tokens above, in an age file encrypted with a passphrase you choose - age -d opens it too. It asks for your owner PIN when one is set.

Make or import it on Export / Import, where it goes straight to your download, encrypted, behind your PIN, and is listed by name only when imported; or at a terminal. No private key or token value is ever shown in a page.
