# ============================================================================
# Authentication Access Manager (authama) environment - TEMPLATE (committed).
# Generates the real, gitignored <config home>/.env. Quote any value with
# spaces or special characters: GH_TOKEN="cmd:op read op://Private/GitHub/token".
#
# Generate the production .env (created 0600, never committed):
#     authama init                 # seeds .env from this file
#     # or:  cp .env-example ~/.config/authama/.env && chmod 600 ~/.config/authama/.env
#     make perms                  # re-asserts 0600 on secrets at any time
#
# Rules:
#   - This file documents SHAPE ONLY - keep values empty here.
#   - Prefer REFERENCES (1Password item, age recipient) over plaintext secrets.
#   - .env is gitignored and must stay mode 0600: authama refuses to load a
#     .env that group or other users can read.
#   - authama loads <config home>/.env at startup. A variable already set in
#     the environment wins over this file; authama.json fills what is left.
#     Skip the file for one run with --no-dotenv or AUTHAMA_NO_DOTENV=1.
#   - Lines may use KEY=value, KEY="quoted value", KEY='literal' and an
#     `export ` prefix; # starts a comment. A malformed line is skipped with a
#     warning naming its line number (never its value).
# ============================================================================
